156 2FA 工具介绍

📅 2026年9月12日 ⏱️ 8分钟阅读 🏷️ 2FA · 安全工具 · 本地优先 · 多用户 · TOTP

📖 这是什么

156 2FA 是一款纯本地运行、多用户隔离、零云端依赖的动态验证码工具。它不托管任何数据，不依赖第三方服务，所有的账户密钥都以加密形式保存在你自己的电脑里，主密码只用于本机校验和解密。

你可以把它理解为：一个属于你自己的、可自行备份迁移的 2FA 保险库。

✨ 核心特点

  • 纯本地运行：所有计算、解密、验证码生成，全部在你本机完成，不上传网络。
  • 多用户支持：不同用户可以拥有各自独立的加密保险库，数据彼此隔离，互不干扰。
  • 加密存储：账户密钥以加密 JSON 形式保存，主密码通过 Argon2id 校验后用于解密。
  • 标准 TOTP 算法：支持 SHA1 / SHA256 / SHA512，支持 6 位 / 8 位验证码，支持 30 秒 / 60 秒周期。
  • 多种导入方式：支持手动输入密钥、上传二维码图片、粘贴 otpauth 链接导入。
  • 备份与迁移：支持导出加密备份（.json），也支持导出 otpauth 明文文本（.txt）用于迁移到其他验证器。
  • 无广告、无追踪、无网络请求：不依赖任何云服务，不采集任何用户数据。

📋 使用方式

1. 启动程序

运行本地 Python 服务，程序会自动打开一个本地 Web 页面（默认监听 127.0.0.1 的随机端口）。

2. 登录

首次使用时，你可以创建一个本地账户。输入用户名和主密码，程序会用 Argon2id 校验密码，并用该密码解密属于你的加密保险库。

3. 添加账户

在“添加账户”弹窗中，你可以通过三种方式导入 2FA 账户：

  • 手动输入：填写备注名称、发行方（可选）、Base32 密钥、算法、位数、周期。
  • 二维码图片：上传包含 otpauth 信息的二维码图片，程序会自动解析出密钥。
  • 链接导入：粘贴 otpauth:// 格式的链接，程序会自动提取密钥和参数。

4. 查看验证码

登录后，主界面会显示所有账户的当前动态验证码，并配有倒计时圆环。每 30 秒自动刷新一次。

5. 管理数据

在设置页面中，你可以：

  • 切换用户：锁闭当前保险库，返回登录界面，各用户数据独立。
  • 导出备份：导出加密备份（.json）或 otpauth 明文文本（.txt）。
  • 导入数据：支持“合并追加”和“覆盖全部”两种模式。
  • 重置程序：删除本地保存的全部用户及其账户数据，恢复首次使用状态。

🔐 安全说明

  • 主密码只在本机使用：密码用于 Argon2id 校验，并派生出用于解密保险库的密钥。密码不会上传网络，不会写入任何日志。
  • 数据加密存储：账户密钥以加密 JSON 形式保存在程序目录下的 data/vault.json。即使文件被复制，没有主密码也无法解密。
  • 本地服务不暴露公网：服务只监听 127.0.0.1，局域网内其他设备无法访问。
  • 安全前提：本工具假设当前电脑为可信设备。如果电脑已被黑客控制，任何本地工具都无法保证密钥安全。

✅ 正是这种“本地优先 + 加密存储 + 多用户隔离”的设计理念，让这款工具在隐私保护上值得信赖。

👥 适用人群

  • 希望把 2FA 密钥完全掌握在自己手里，不想依赖云端验证器的用户。
  • 需要在一台电脑上为多个用户提供独立 2FA 保险库的用户。
  • 对隐私敏感，希望使用纯本地、零网络请求工具的用户。
  • 开发者或技术爱好者，想了解 TOTP 原理和本地加密存储的实现方式。

📌 结语

156 2FA 不是要取代所有验证器，而是提供一个完全由你掌控的本地选项。

它不承诺“绝对安全”，但它承诺：你的密钥不会离开你的电脑，你的主密码不会上传网络，你的数据可以随时备份和迁移。

💡 温馨提示：主密码是解锁保险库的唯一凭证，请务必妥善保管，不要泄露给任何人。
