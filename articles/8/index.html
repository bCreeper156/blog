软件测评#5 - Ditto

📅 2026年8月16日 ⏱️ 6分钟阅读 🏷️ 软件测评 · Ditto · 剪贴板工具

写 Markdown 的时候，剪贴板就是第二条手。

Win+V 用久了，总觉得差点意思——历史只有 25 条，重启还会清，想找上周复制过的一段配置只能靠滚轮硬翻。于是很多人跟我说：试试 Ditto。

我试了，认真用了一段。下面是它确实能做的事，以及为什么我最后还是把它卸了。

📌 文件资源提示：本文相关安装包与便携版可在文末资源区获取，或前往博客内下载页查看。

Ditto 到底是什么

Ditto 是 Scott Brogden 维护的一款 Windows 剪贴板增强工具，2000 年代就存在了，开源，用 SQLite 存本地历史。便携版解压仅几 MB，常驻内存极低，默认热键 Ctrl+`（反引号）呼出面板，和 Win+V 互不冲突。

它有三个主要维护渠道：官网、GitHub Releases 与微软商店。为避免下到修改版，建议只从上述渠道获取。

它把剪贴板从"中转站"变成了"本地库"

认真用起来，Ditto 和 Win+V 的差距不在"能存几条"，而在下面几件事：

1. 容量不再是 25 条

你可以设 5000、10000 条，文本、代码、图片、HTML、文件对象都进同一张表，重启不丢，不绑微软账号。

2. 能搜索

面板顶部一个输入框，敲 json、ssh、2026规划，几个月前复制过的一段代码直接命中。Win+V 只能靠手滚。

3. 纯文本粘贴

写 MD 最怕从网页拷一段带颜色带缩进的富文本。Ditto 右键条目 → "粘贴为纯文本"，进编辑器就是干净字。

4. 合并粘贴

历史里选中三条、五条，右键"合并粘贴"，一次性按换行吐出来。搬客服话术、拼接口参数时有用。

5. 分组 + 钉住 + 局域网同步

常用邮箱、SSH 命令、签名存一个"常用"组，设快捷键直贴；多台电脑走局域网同步，不走云。

这些功能叠在一起，确实把"剪贴板管理器"这个品类能做到的极致给到了。

但我的真实用量是：顶多五条切换

用了很长一段时间后，我发现自己有个很固定的习惯：

  • 复制完基本当场粘走，活过半天的条目很少
  • Win+V 的 25 条上限，我从来没触过顶
  • 三个月前复制过什么，我记不住，也没打算去查
  • 纯文本粘贴？Win+V 右键条目也能做到
  • 合并粘贴？我一年用不到几次
  • 分组、局域网同步？对我单机写字的人来说是闲置能力

也就是说，Ditto 最值钱的"历史检索"和"大容量"，恰好压在我用不上的地方。它没不好，是我这五条切换的工作流，喂不饱它。

谁该装，谁可以跳过

  • 日拷百段的程序员、背话术的运营/客服、不绑微软账号的多机办公党：Ditto 是刚需，装，别犹豫
  • 像我这样顶多五条来回切、偶尔粘纯文本、Win+V 右键够用的人：Win+V + 钉两条常用地址/签名，已经活得很舒服

工具好不好，不看功能清单长度，看它能不能塞进你的工作流。

结尾

Ditto 把剪贴板能做到的极致都给你了。只是对我这种"五条切换党"来说，这份极致有点太重。

最后我还是卸掉了它。倒不是它不好，只是我真的用不上。
