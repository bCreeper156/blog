## 使用指南

如果你已经确认完成修改，请打开[Cloudflare](https://dash.cloudflare.com)并登录，点击worker与pages，创建应用程序，点击下方创建pages，然后上传你下载的博客模板，
选中仓库后，进入设置页面，请按下表填写：

· 项目名称：随意填（如 my-blog），这会生成 项目名.pages.dev 的临时域名。
· 生产分支：保持默认的 main 或 master。
· 框架预设：下拉框选择 无（None）。
· 构建命令：直接清空，一个字都不填。
· 构建输出目录 / 工件目录：填 /（代表根目录）。
