## Usage Guide

If you have confirmed that you have completed the modifications, please open [Cloudflare](https://dash.cloudflare.com) and log in. Click on Workers & Pages, create an application, click on Create Pages below, and then upload the blog template you downloaded. After selecting the repository, go to the settings page and fill in the following information:

· Project Name: Enter anything (e.g., my-blog). This will generate a temporary domain name: project_name.pages.dev.

· Production Branch: Keep the default main or master.

· Framework Preset: Select None from the dropdown.

· Build Command: Leave it blank.

• Build the output directory / artifact directory: Fill in / (representing the root directory).
